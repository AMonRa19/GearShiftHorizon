# GearShiftHorizon 0.20.0 — Python Edition

Полная Python-ветка проекта. Предыдущие Rust-версии v0.18.0 и v0.19.0 сохранены отдельно и не изменяются.

## Архитектура

- Telemetry Engine — приём UDP и разбор подтверждённых полей FH telemetry (324 байта, offsets перенесены из прежнего парсера).
- Vehicle State Analyzer — анализ изменения скорости во времени, педалей и wheel slip; педаль тормоза сама по себе не считается доказательством замедления.
- Per-car Calibration — отдельный профиль по car_ordinal, обучение RPM/speed на передачах и кривой мощности.
- Shift Controller — прогноз оборотов на целевой передаче, cooldown, подтверждение передачи и защитные блокировки.
- PySide6 UI + HUD — главное окно и отдельное прозрачное окно поверх игры.

Неизвестные байты пакета не интерпретируются. Ускорение вдоль продольной оси пока вычисляется как производная скорости, потому что оси accel_x/y/z не размечены как продольная/поперечная нагрузка без отдельной верификации.

## Установка (Windows 10/11)

1. Установить Python 3.12 x64.
2. Открыть PowerShell в папке проекта.
3. Выполнить:

    py -3.12 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -e ".[dev]"
    python -m gearshift.app

Включить в FH Data Out / UDP: адрес 127.0.0.1, порт 5555. Клавиши E/Q должны быть назначены на повышение/понижение.

## HUD

Нажать HUD: ВКЛ в основном окне. HUD — отдельное прозрачное окно поверх игры, его можно перетаскивать мышью. Для стабильного отображения поверх игры рекомендуется безрамочный оконный режим.

## Безопасность

Автоматические переключения по умолчанию выключены. Сначала проверьте телеметрию, состояния, обученные отношения передач и прогноз RPM. Не включайте автоматический режим, пока профиль не собрал достаточные данные на конкретном автомобиле. Класс/PI — метаданные, но не замена индивидуальной калибровке.

## Ограничения первого этапа

- В текущей итерации распознаются только подтверждённые поля предыдущего 324-байтового парсера; новые offsets не угадываются.
- Обучение отношений RPM/speed является оценкой, а не чтением передаточных чисел из меню тюнинга.
- Реальное поведение HUD поверх эксклюзивного fullscreen зависит от режима отображения игры.
- Эта ветка — первый перенос ядра и интерфейса. Требуется CI и проверка телеметрии/ввода непосредственно в FH6 до использования автоматического управления в гонке.
