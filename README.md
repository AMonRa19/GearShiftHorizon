# GearShiftHorizon 0.20.0 — Python Edition

Полная Python-ветка проекта. Предыдущие Rust-версии v0.18.0 и v0.19.0 сохранены отдельно и не изменяются.

## Архитектура

- Telemetry Engine — приём UDP и разбор полного 324-байтового FH6 Data Out: динамика, подвеска, slip ratio/angle/combined slip, wheel speeds, rumble/puddle, car metadata, collision data, position, speed, power/torque, tire temperatures, boost, fuel, lap data and player inputs. Offsets сверены с официальной спецификацией Forza Horizon 6.
- Vehicle State Analyzer — анализ разгона/торможения по изменению скорости во времени, боковой динамики, скольжения, вероятного airtime и столкновений.
- Per-car Calibration — отдельный профиль по car_ordinal, обучение RPM/speed на передачах и кривой мощности.
- Shift Controller — прогноз оборотов на целевой передаче, power-model kickdown, cooldown, подтверждение передачи и защитные блокировки.
- PySide6 UI + HUD — главное окно и отдельное прозрачное окно поверх игры.

Неизвестные байты пакета не интерпретируются. Оси локальной системы координат по документации: X — вправо, Y — вверх, Z — вперёд. Единицы некоторых acceleration/tire temperature полей спецификация явно не фиксирует, поэтому UI показывает их raw-значения без догадок. Продольное ускорение для классификации торможения вычисляется отдельно по производной скорости.

## Установка (Windows 10/11)

1. Установить Python 3.12 x64.
2. Открыть PowerShell в папке проекта.
3. Выполнить:

    py -3.12 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -e ".[dev]"
    python -m gearshift.app

Включить в FH Data Out / UDP: адрес 127.0.0.1, порт 5555. Клавиши E/Q должны быть назначены на повышение/понижение.

## HUD

Нажать HUD: ВКЛ в основном окне. HUD — отдельное прозрачное окно поверх игры, его можно перетаскивать мышью. Размер и прозрачность меняются ползунками и сохраняются вместе с позицией. Для стабильного отображения поверх игры рекомендуется безрамочный оконный режим.

## Безопасность

Автоматические переключения по умолчанию выключены. Для отправки E/Q Forza должна быть активным окном Windows. Сначала проверьте телеметрию, состояния, обученные отношения передач и прогноз RPM. Не включайте автоматический режим, пока профиль не собрал достаточные данные на конкретном автомобиле. Класс/PI — метаданные, но не замена индивидуальной калибровке.

## Ограничения первого этапа

- Парсер следует официальной FH6 Data Out схеме на 324 байта; формат сверяется с [официальной документацией Forza Horizon 6](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation).
- Обучение отношений RPM/speed является оценкой, а не чтением передаточных чисел из меню тюнинга.
- Airborne — вероятностный вывод по четырём датчикам хода подвески, а не прямой флаг контакта колёс с землёй.
- Реальное поведение HUD поверх эксклюзивного fullscreen зависит от режима отображения игры.
- Эта ветка — первый перенос ядра и интерфейса. Требуется CI и проверка телеметрии/ввода непосредственно в FH6 до использования автоматического управления в гонке.
